# FitZone

Навчальний вебсайт онлайн-бронювання занять фітнес-студії (лабораторні роботи № 1–4).

- HTML і CSS — лабораторна робота № 3 (папка `css/`)
- JavaScript — лабораторна робота № 4 (папка `js/`: `main.js`, `validation.js`, `booking.js`, `widgets.js`)

Дані (користувач, бронювання, налаштування) зберігаються у браузері (localStorage / sessionStorage).
Щоб скинути демонстраційні дані: DevTools → Application → Clear site data.
Тестовий номер картки для оплати: 4111 1111 1111 1111.
